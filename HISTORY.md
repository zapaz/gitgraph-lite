# Release history

[← GitGraph Lite](README.md) · [Download latest](https://github.com/zapaz/gitgraph-lite/releases/latest) · [User & developer guide](docs/guide.md)

All published application versions are available from the linked GitHub releases. Downloads target Apple Silicon and macOS 13 or later. Each release provides an app ZIP and SHA-256 checksums; the MIT license is bundled in the application.

## Recent milestones

- **0.16** — Unified diff by default with description, files and diff on one row; side by side puts the diff below. Redesigned file tree with guides, icons and status letters.
- **0.15** — **About** popup (ⓘ button and app menu) with the version and the app's principles; every label and tooltip in English.
- **0.14** — **Diff** checkbox to hide or show the commit details and diff; the window's branch and worktree folder (each copyable) move into the header beside a compact search field and **Open repo…**; a small “w” on the computer icon marks a branch with a worktree, whose path appears on hover.
- **0.13** — One branch menu on every part of a branch badge, with a **Delete** submenu (local + origin, local, remote, worktree); **Open Branch** creates the worktree when needed; every delete asks for confirmation; Lite tag menu (Delete Tag, Push, Copy Name) across all remotes.
- **0.12** — Every commit action runs in one popup (input, progress, result or error) with copy buttons; Lite commit menu; merge always creates a merge commit; Abort/Continue on conflicts; light matching badge icons.
- **0.11** — Short menus for commits, branches, tags and worktrees; full/short hash and path copying; targeted origin Push/Pull and tag publication.
- **0.10.7** — Faster loading and filtering, with [reproducible measurements](docs/performance-0.10.7.md).
- **0.10.6** — Always-visible + / − controls to expand and collapse a commit chain.
- **0.10** — Local branches with lazy, dedicated workspaces and repository-scoped associations.
- **0.9** — Locally stored action-frequency ranking.
- **0.8** — Multi-branch browsing, pins and compact history refinements.
- **0.1** — First runnable native macOS history browser with graph, diffs, comparison, search and automatic refresh.
