# Release history

[← GitGraph Lite](README.md) · [Download latest](https://github.com/zapaz/gitgraph-lite/releases/latest) · [User & developer guide](docs/guide.md)

All published application versions are available from the linked GitHub releases. Downloads target Apple Silicon and macOS 13 or later. Each release provides an app ZIP and SHA-256 checksums; the MIT license is bundled in the application.

## Recent milestones

- **0.11** — Short menus for commits, branches, tags and worktrees; full/short hash and path copying; targeted origin Push/Pull and tag publication.
- **0.10.7** — Faster loading and filtering, with [reproducible measurements](docs/performance-0.10.7.md).
- **0.10.6** — Always-visible + / − controls to expand and collapse a commit chain.
- **0.10** — Local branches with lazy, dedicated workspaces and repository-scoped associations.
- **0.9** — Locally stored action-frequency ranking.
- **0.8** — Multi-branch browsing, pins and compact history refinements.
- **0.1** — First runnable native macOS history browser with graph, diffs, comparison, search and automatic refresh.
